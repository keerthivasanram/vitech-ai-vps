# EVERY VERSION IS PINNED, and that is deliberate. Ten of these were unpinned
# until 2026-09-01, which the production-readiness review flagged as the same
# version-drift trap already guarded on the Flowise side with an `overrides`
# block. It is not theoretical here: fpdf2 has broken this codebase TWICE from
# an unpinned upgrade - `circle()` changed from bounding-box to centre+radius
# (every drawing balloon rendered at twice size, offset up-left), and an
# explicit (w, h) page format started being swapped when orientation="L" was
# also passed (a 420x297 landscape sheet came out 297x420 portrait).
#
# These are the versions the platform is verified against: twelve test suites
# green, goldens byte-identical, 28 HTTP contract fingerprints matched. Upgrade
# ONE at a time, deliberately, and run the suites before and after.
